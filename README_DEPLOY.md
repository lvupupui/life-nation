# GitHub Pages 上线说明

把本文件夹内所有文件上传到 GitHub 仓库根目录即可。

必须包含：
- index.html
- style.css
- script.js
- manifest.json
- sw.js
- 404.html
- .nojekyll
- assets/

开启方式：
1. 进入 GitHub 仓库 Settings
2. 打开 Pages
3. Source 选择 Deploy from a branch
4. Branch 选择 main / root
5. 保存等待 1-3 分钟

访问格式：
https://你的用户名.github.io/仓库名/
